# Web Programming Lab: Bean & Byte Café ☕

Over 8 classes you'll build a working website for a (pretend) café at UNIMAS, **Bean & Byte Café**, one feature at a time, and finish with a live site on the internet.

| Class | Topic | What you add to the café site |
|---|---|---|
| 1 | [HTML basics](class-01/) | Your first page: headings, paragraphs, bold, line breaks, an embedded map |
| 2 | [More HTML](class-02/) | Links, lists, images, a menu table, an order form |
| 3 | CSS + Bootstrap | Colours, fonts and layout; looks good on phones |
| 4 | JavaScript | Interactive order form and live price total |
| 5 | PHP | Handle the order form on the server |
| 6 | SQL + PHP | Store the menu and orders in a MySQL database |
| 7 | Authentication + APIs | Staff login; a menu API |
| 8 | Hosting + SEO/AEO | Put the site live and help people find it |

New class folders appear here as the course goes on.

## Getting started

**Before Class 1:** follow the [Setup Guide](setup/setup-guide.md).

## How each class works

1. Open that class's folder, for example `class-01/`.
2. Read its `README.md`. It lists the tasks.
3. Do your work in the `starter/` folder. Look for the `TODO` comments.
4. Finished early? Try the **stretch challenges** at the end of the README.

**Fell behind?** No problem. Each class's `starter/` folder includes the finished work from the class before, so you can always pick up from there.

## Git routine

**At the start of class: get the new class's files**
1. On GitHub, open **your fork** and click **Sync fork → Update branch**.
2. In VS Code: open the **Source Control** panel → **⋯** menu → **Pull**.
   (Command line: `git pull`)

**At the end of class: save your work to GitHub**
1. In VS Code, open the **Source Control** panel (the branch icon in the left sidebar).
2. Type a short message, for example `Class 1: finished home page`.
3. Click **Commit**, then **Sync Changes**.
   (Command line: `git add .`, then `git commit -m "your message"`, then `git push`)

> Only edit files inside the `starter/` folders (and new files you create there). That way, syncing new classes never clashes with your work.

## About your assignment

What you learn here applies directly to your e-commerce assignment: a menu becomes a product list, an order form becomes a checkout, and so on. Use the café as a **reference**. Your assignment must be your own design and your own code.
